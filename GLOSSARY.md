# GYM-8020

Krachttraining volgens de 80/20-methode: per oefening een zware en een lichte set tot falen. Deze lijst legt
de gedeelde taal vast. We praten Nederlands; de Engelse term (na **EN**) is wat in code en Engelse
schermteksten terugkomt. Beide woorden betekenen hetzelfde.

## Trainen

**Oefening** (EN: Exercise):
Eén beweging met een vaste uitvoering, zoals back squat of pull-up.

**Workout** (EN: Workout):
Een vaste reeks oefeningen die je in één keer doet, zoals "Full body".
_Vermijd_: schema

**Programma** (EN: Program):
Een set workouts met een weekdoel (hoe vaak per week), waarvan er één actief is.
_Vermijd_: weekplan

**Sessie** (EN: Session):
Eén keer trainen: een workout die je op een bepaald moment uitvoert. Op het Nederlandse scherm heet dit
"Training".
_Vermijd_: training (als term in gesprek)

**Set** (EN: Set):
Eén reeks herhalingen van een oefening, met een rol: zwaar, licht of warming-up.

**Zware set / lichte set** (EN: Heavy set / Light set, afgekort H / L):
De twee werksets van de methode: zwaar met weinig reps, licht met veel reps, beide tot falen.
_Vermijd_: Z/L in Engelse tekst

**Warming-up** (EN: Warm-up):
Een set vóór de werksets om op te warmen; telt niet als werkset.

**Progressie op gewicht / op reps** (EN: Weight progression / Reps progression):
Per oefening ingesteld: bij gewicht groei je in kilo's, bij reps groei je in aantal herhalingen.

**Materiaal** (EN: Equipment):
Wat je gebruikt om gewicht te maken (stang, dumbbells, kabel, machine, ondersteuning), met de stappen die
het toelaat.
_Vermijd_: material

## Doelen en prestaties

**Prestatie** (EN: Performance):
Wat je in een sessie bij een oefening echt deed: per set gewicht en reps.

**Doel** (EN: Target):
Wat jij voor de volgende keer van een oefening vastzet: per set een gewicht en/of aantal reps. Alleen jij
zet een doel.
_Vermijd_: plan, next time, goal

**Advies** (EN: Advice):
Een voorstel van de app voor het doel, op basis van je prestatie. Wordt nooit vanzelf een doel.
_Vermijd_: suggestie, suggestion

**Laatste keer** (EN: Last time):
Binnen het trainen: de prestatie van een oefening in de meest recente sessie waarin je die oefening echt
deed.

**Vergelijking** (EN: Comparison):
Buiten het trainen (samenvatting, dashboard): je resultaat naast een eerder resultaat, per oefening, spier,
spiergroep of workout. Wat "eerder" daar betekent, leggen we per niveau vast; het is niet hetzelfde als
laatste keer.
_Vermijd_: vs. last time (als algemene term)
