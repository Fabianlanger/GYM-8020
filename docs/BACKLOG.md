# Backlog

**Verhuisd naar GitHub Issues** (oktober 2026, na de invoering van de skills van Matt Pocock):
https://github.com/Fabianlanger/GYM-8020/issues

- Elk open punt is een issue; de oude code (B-6, V-2, W-1, …) staat vooraan in de titel.
- Releases zijn **mijlpalen** (0.7, 0.8, 0.9, 0.10, 1.0, Later). Doelen en afhankelijkheden per release: `ROADMAP.md`.
- Punten met open vragen hebben het label `needs-info`, met de vragen en het advies in het issue.
- De review van doelen, advies, laatste keer, materiaal en vergelijking loopt als **Wayfinder-kaart**
  ("Kaart: het doel is van jou", issue #1); de achtergrond staat in `review-doelen.md`.
- Nieuwe punten komen voortaan via `/wayfinder` (grote, vage onderwerpen) of rechtstreeks als issue.

De volledige oude backlog, inclusief afgeronde punten, staat in de git-geschiedenis van dit bestand.
